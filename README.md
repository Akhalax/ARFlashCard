# Автоматизоване створення двомовних флеш-карток для інтерактивної маркерної доповненої реальності

## Команда проєкту:
- Олександр Блажко, доцент кафедри інформаційних систем Національного університету «Одеська політехніка»
- Олександр Халаміренко, аспірант кафедри інформаційних систем Національного університету «Одеська політехніка»

### Посилання на програму зі створення файлів зображень та аудіо-файлів
- https://information-system-ics.github.io/ARFlashCard/utils/ar-cards-generator.html

### Основні кроки використання програми:
1)	додати список англомовних слів;
2)	обрати мову зі списку доступних «Target Language Words»: Англійська, Іспанська, Італійська, Німецька, Польська, Португальська, Французька;
3)	перекласти список слів (кнопка «Translate»);
4)	налаштувати властивості зображення: розміри, колір фону, слів, зображення-іконки, розташування іконки по відношенню до слова;
5)	згенерувати зображення (кнопка «Generate All Bilingual Images»), яке містить зображення слова та іконку, яку автоматично отримано із сервісу іконок;
6)	вказати API Key для генерації аудіо-файлів з промовою слів;
7)	згенерувати аудіо-файли (кнопка «Generate All Audio»);
8)	переглянути згенеровані файли із зображеннями та аудіо-файли;
9)	за бажанням змінити автоматично згенеровані іконки на інші;
10)	зберегти архів із файлами зображень (кнопка «Download Images ZIP») та 
архів із аудіо-файлами (кнопка «Download Audio ZIP»).

### Конфігурації та медіафайли
- конфігурації лежать у теці `config/` (`config/config.json` — за замовчуванням), медіафайли (зображення, аудіо, відео, моделі) — у `config/media/`;
- у конфігурації вказуються лише імена медіафайлів, наприклад `"textureFile": "en_Man.jpg"` → `config/media/en_Man.jpg`;
- інша конфігурація відкривається параметром адреси: `index.html?config=config_aruco` → `config/config_aruco.json`;
- інша тека з медіа для конфігурації: `"settings": { "mediaFolder": "media-pt/" }` (відносно `config/`).

### Автоматичне створення config.json
- **У генераторі** (панель «AR App Config»): обрати тип маркерів (Barcode 3x3 або ArUco), за потреби вказати номери надрукованих маркерів у порядку карток (по 2 на пару слів; порожнє поле — автоматично), номер маркера-вказівника та розміри карток.
  - «Download config.json» — лише файл конфігурації;
  - «Download AR Bundle ZIP» — зображення, аудіо, картинка «?» (`<мова>_question.jpg`), `config.json` і `cards.json` (список пар) у структурі `config/` + `config/media/`; архів розпаковується в теку застосунку (поруч з `index.html`).
- **Зі своєї теки з файлами** — сторінка `utils/config-builder.html`:
  https://information-system-ics.github.io/ARFlashCard/utils/config-builder.html
  - обрати теку застосунку, `config/` або `config/media/` — сторінка бере медіафайли з `media/`, а готовий `config.json` зберігається в `config/`;
  - файли називаються `<мова>_<слово>.jpg` / `.mp3`, як їх створює генератор;
  - пари слів визначаються за `cards.json` з генератора, за спільним номером (`01_en_Man.jpg` + `01_pt-pt_Homem.jpg`), за підтекою (`Man/en_Man.jpg` + `Man/pt-pt_Homem.jpg`) або вручну на сторінці;
  - картинка «?» розпізнається за словом `question` (`pt-pt_question.jpg`, `pt-question.jpg`).

### Створення AR-флеш-карток
- картки із маркерами можуть бути заздалегідь підготовлені (роздруковані або намальовані) для будь-яких наборів слів двох мов.
- приклад ArUco-маркерів для 3-х карток та Barcode-маркеру для контролера

# Автоматизоване створення двомовних флеш-карток для інтерактивної маркерної доповненої реальності

## Команда проєкту:
- Олександр Блажко, доцент кафедри інформаційних систем Національного університету «Одеська політехніка»
- Олександр Халаміренко, аспірант кафедри інформаційних систем Національного університету «Одеська політехніка»

### Посилання на програму зі створення файлів зображень та аудіо-файлів
- https://information-system-ics.github.io/ARFlashCard/utils/ar-cards-generator.html

### Основні кроки використання програми:
1)	ввести терміни (по одному в рядку) і визначення (у тому ж порядку) — або вставити рядки `Термін — Визначення` і натиснути «Split»;
2)	налаштувати вигляд карток: розмір, кольори, літери-позначки («Т» — термін, «В» — визначення), розмір шрифту;
3)	згенерувати картки (кнопка «Generate all card images»): картка терміна, картка визначення і дві закриті картки «?» (`question_term.jpg`, `question_definition.jpg`);
4)	обрати голос і згенерувати аудіо (кнопка «Generate all audio»), попередньо можна прослухати перший термін; аудіо картки починається з фрази-підказки, напр. «Дайте визначення терміну: Атом»;
5)	переглянути картки та прослухати аудіо;
6)	налаштувати маркери у панелі «AR App Config» і завантажити готовий набір (кнопка «Download AR Bundle ZIP»).

### Озвучення
- **Piper** (за замовчуванням) — українські голоси, що працюють прямо в браузері: безкоштовно, без ключів і без сервера. За замовчуванням — Олекса (high, 114 МБ), який найкраще ставить наголоси; також доступні Тетяна, Микита, Лада (medium, 77 МБ), Тетяна, Микита (high, 114 МБ) і Лада (x_low, 21 МБ). Модель голосу завантажується один раз із [rhasspy/piper-voices](https://huggingface.co/rhasspy/piper-voices) і зберігається в браузері; аудіо зберігається у форматі MP3.
- **Azure AI Speech** — найякісніші українські нейромережеві голоси (Поліна, Остап). Потрібен власний ключ: на порталі Azure створити ресурс **Speech** (безкоштовний рівень F0 — 0,5 млн символів на місяць), у розділі *Keys and Endpoint* скопіювати **Key 1** і **Location/Region** та вставити їх у генератор. Ключ надсилається лише до сервісу Microsoft і не потрапляє в архів чи конфігурацію; за бажанням його можна запам'ятати в цьому браузері.
- **VoiceRSS** — для інших мов (потрібен безкоштовний API Key з [voicerss.org](https://www.voicerss.org/)); української мови не підтримує.

### Режими роботи AR-застосунку
Після запуску обирається режим:
- **«Картка»** — з маркером-вказівником (контролером): обидві картки пари спочатку закриті «?»; дотик вказівником відкриває картку, вмикає її звук і показує підказку внизу екрана; одночасно в кадрі може бути кілька карток.
- **«Фішка»** — без вказівника: усі картки одразу показують свій вміст (термін або визначення), а звучить і підписується лише картка, що з'явилася в кадрі першою.

Підказки (поле `caption` у конфігурації): для терміна — «Дайте визначення терміну – …», для визначення — «Якому терміну відповідає визначення – …». Текст фраз задається в панелі «AR App Config» генератора.

Обидва режими використовують одну й ту саму конфігурацію.

### Конфігурації та медіафайли
- конфігурації лежать у теці `config/` (`config/config.json` — за замовчуванням), медіафайли (зображення, аудіо, відео, моделі) — у `config/media/`;
- у конфігурації вказуються лише імена медіафайлів, наприклад `"textureFile": "en_Man.jpg"` → `config/media/en_Man.jpg`;
- інша конфігурація відкривається параметром адреси: `index.html?config=config_aruco` → `config/config_aruco.json`;
- інша тека з медіа для конфігурації: `"settings": { "mediaFolder": "media-pt/" }` (відносно `config/`).

### Автоматичне створення config.json
- **У генераторі** (панель «AR App Config»): обрати тип маркерів (Barcode 3x3 або ArUco), за потреби вказати номери надрукованих маркерів у порядку карток (по 2 на пару: термін, визначення; порожнє поле — автоматично), номер маркера-вказівника та розміри карток.
  - «Download config.json» — лише файл конфігурації;
  - «Download AR Bundle ZIP» — картки, аудіо, закриті картки «?», `config.json` і `cards.json` (список пар із текстами) у структурі `config/` + `config/media/`; архів розпаковується в теку застосунку (поруч з `index.html`).
- **Зі своєї теки з файлами** — сторінка `utils/config-builder.html`:
  https://information-system-ics.github.io/ARFlashCard/utils/config-builder.html
  - обрати теку застосунку, `config/` або `config/media/` — сторінка бере медіафайли з `media/`, а готовий `config.json` зберігається в `config/`;
  - файли називаються так, як їх створює генератор: `01_term_<термін>.jpg / .mp3` і `01_definition_<термін>.jpg / .mp3`;
  - пари визначаються за `cards.json` з генератора, за спільним номером (`01_term_…` + `01_definition_…`), за однаковою назвою (`term_Атом.jpg` + `definition_Атом.jpg`) або вручну на сторінці;
  - закриті картки «?» — файли `question_term.jpg` і `question_definition.jpg` (або один `question.jpg` для обох);
  - повні тексти для підказок беруться з `cards.json`; без нього для визначень показується лише фраза без тексту (щоб не підказати відповідь).

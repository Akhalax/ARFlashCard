🔊 Audio

🗣️ Piper voices run on this computer (open-source models from rhasspy/piper-voices). The first use downloads the voice (21–114 MB) once; after that it is stored in the browser and works quickly. Speech is saved as MP3.

🔗 Free key at voicerss.org (500 requests/day). VoiceRSS has no Ukrainian voice.

🧩 AR App Config (config.json)

Builds config.json for the AR app: a pointer marker plus two cards per pair (term card and definition card). The same config works in both app modes: "Card" (with the pointer) and "Chip" (without it). The bundle ZIP contains config/config.json, config/cards.json and config/media/… — unpack it into the app folder (next to index.html). To build a config from an existing folder of files, use the Config Builder.

🧩 AR Flashcard Config Builder

1. Choose the folder with card files

Choose the app's config folder, its media folder, or a folder with the same layout. The app reads configs from config/ and media from config/media/, so file paths in config.json are relative to media/. Files are named <language>_<word>.jpg / .mp3, as the generator creates them. Words of a pair are matched by:

  • cards.json written by the generator (bundle ZIP) — exact pairs and order;
  • a shared number prefix: 01_en_Man.jpg + 01_pt-pt_Homem.jpg;
  • a sub-folder per pair: Man/en_Man.jpg + Man/pt-pt_Homem.jpg;
  • the same word in both languages; everything else can be paired by hand below.

"?" images are recognised by the word question, e.g. pt-pt_question.jpg or pt-question.jpg.

🧩 AR Flashcard Config Builder

1. Choose the folder with card files

Choose the app's config folder, its media folder, or a folder with the same layout. The app reads configs from config/ and media from config/media/, so file paths in config.json are relative to media/. Files are named as the generator creates them: 01_term_<term>.jpg / .mp3 and 01_definition_<term>.jpg / .mp3. A term and its definition are matched by:

  • cards.json written by the generator (bundle ZIP) — exact pairs, order and texts;
  • the shared number: 01_term_Атом.jpg + 01_definition_Атом.jpg;
  • the same name without a number: term_Атом.jpg + definition_Атом.jpg;
  • one term and one definition in a sub-folder; everything else can be paired by hand below.

The "?" images of hidden cards are question_term.jpg and question_definition.jpg (question.jpg is used for both if the separate ones are missing). The on-screen prompts use the full texts from cards.json; without it only the term name is known.
